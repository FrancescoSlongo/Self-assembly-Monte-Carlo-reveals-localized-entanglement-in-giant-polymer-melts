Self-Assembly Monte Carlo (SAMC) sampling scheme.
Here we present the code to sample ring-linear polymer blends at full space-filling with SAMC and prepare the configurations for the analysis.

===========================================================================================================================================

CONTENT
After unzipping, the "SAMC_package" directory should contain:
  - "source_code" directory. It contains the files
      functions.h ------------------> header file with functions for sampling configurations and chain coordinates extraction
      functions.c ------------------> functions implementation
      main_sampling.c --------------> code for running the SAMC simulation
      main_chain_coordinates.c -----> code for extracting chain coordinates
      launch_sampling.sh -----------> script to launch SAMC simulation
      launch_chain_coordinates.sh --> script to launch chain coordinates extraction
  - "100x100x100_10linear" directory. It contains
      INPUT_PARAMETERS.DAT ---------> input file with SAMC simulation parameters (lattice dimension and side, number of linear chains, number of dumps and steps per dump)
      configurations ---------------> directory for the sampled configurations files (initially empty)
      chain_coordinates ------------> directory for the sampled configurations files in coordinates format (initially empty)
      exe --------------------------> directory for executable files (initielly empty)
      log --------------------------> directory for scripts' output (initially empty)

IMPORTANT: the user is responsable for obtaining their licenced version of the source code of the "ran2" random number generator of "Numerical Recipes" by Press et al., Sec. 7.1 of the second edition. The corresponding "ran2.h" and "ran2.c" files must be added to the "source_code" directory.

===========================================================================================================================================

EXECUTION
   Here the user finds the list of commands to execute a SAMC simulation that generates 10 independent configurations for the system containing 10 linear chains on the 100x100x100 periodic lattice.

1) Run SAMC simulation. Configurations files will be produced in the directory "100x100x100_10linear/configurations/". Script's output will be written in file "100x100x100_10linear/log/log_sampling.txt"
   Enter the "SAMC_package" directory and execute the script "launch_sampling.sh":
      cd SAMC_package/
      system=100x100x100 ; n_linear_chains=10
      bash ./launch_sampling.sh ${system} ${n_linear_chains}
      cd ..

2) Extract chain coordinates from configurations. Chain coordinates files will be produced in the directory "100x100x100_10linear/chain_coordinates/". Script's output will be written in file "100x100x100_10linear/log/log_chain_coordinates.txt"
   Enter the "SAMC_package" directory and execute the script "launch_chain_coordinates.sh":
      system=100x100x100 ; n_linear_chains=10 config_index=0 # the user should set the configuration to process
      bash launch_chain_coordinates.sh ${system} ${n_linear_chains} ${config_index}
      cd ..

The demo runs, which include the software compilation, typically take a few seconds each to complete on standard Unix Intel-based workstations.

===========================================================================================================================================

CONFIGURATIONS FORMAT
- Configurations files generated by SAMC simulations in the directory "100x100x100_10linear/configurations/" contain each line (i=0, ..., volume-1) the indices of the two lattice sites connected to site i. If site i is an endpoint, one of the connected sites is set to the unphysical value of 2^64-1.

- Configurations files with explicit chain coordinates, generated in the directory "100x100x100_10linear/chain_coordinates/" contain two types of chains:
    linear ---------> self-avoiding-walk with free endpoints
    ring -----------> closed self-avoiding-walk. Some of the rings may correspond to infinite loops in the extended (unwrapped) representation. To distinguish them, a special tag, "winding", is appended in a new line immediately after their coordinates lists.

    The file structure is sketched as follows:
      chain_type length
      x0 y0 z0
      x1 y1 z1
      ...

===========================================================================================================================================

FURTHER INFORMATIONS
- The number of Monte Carlo steps per dump in the input file "INPUT_PARAMETERS.DAT" is hard-coded to 3 autocorrelation times as measured on the demo 100x100x100 systems.
  The user that wishes to use the code for production runs on different system sizes should set the number of steps per dump by either: (i) measure the corresponding autocorrelation time of the edge overlap correlation function, or else (ii) use the scaling function tau_eq = (1.05) * V^1.001 we provide in the article.
- Configurations are enumerated starting from 0.
- Lengths are expressed in terms of number of bonds, therefore linear chains consists of length+1 monomers.
