This repository contains the source code of the self-assembly Monte Carlo (SAMC) introduced in the
study titled "Self-assembly Monte Carlo reveals localized entanglement in giant polymer melts",
by Enrico Fornasa, Francesco Slongo and Cristian Micheletti.
